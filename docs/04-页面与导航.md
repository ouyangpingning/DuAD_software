# 04 页面与导航

## 整体结构

```
App.qml (无边框窗口 + 自定义标题栏)
└── MainuiRoot.qml
    └── MainWindow.ui.qml (侧边栏 + 内容区)
        └── StackLayout (6 个页面)
```

## 无边框窗口（App.qml）

**功能**：隐藏系统标题栏，用自定义标题栏（拖拽移动、双击最大化、三键控制）+ 四边/四角拖拽缩放。

**实现要点**：
```qml
Window {
    flags: Qt.FramelessWindowHint | Qt.Window    // 去掉系统边框
    // 自定义标题栏
    Rectangle {
        MouseArea {
            onPressed: window.startSystemMove()      // 拖拽移动（Qt 内置 API）
            onDoubleClicked: 最大化/还原切换
        }
    }
    // 四边缩放：4px 宽的 MouseArea
    MouseArea { cursorShape: Qt.SizeHorCursor
        onPressed: window.startSystemResize(Qt.LeftEdge) }
    // 四角缩放：8x8 的 MouseArea + SizeFDiagCursor
}
```

**知识点**：
- `startSystemMove()` / `startSystemResize(edge)` 是 QML Window 的内置窗口管理 API（Wayland 下也能用）。
- **component 关键字**：App.qml 里用 `component TitleBtn: Rectangle {...}` 定义**内联组件**（只在当前文件可用），比复制三遍按钮代码干净。

## 侧边栏导航（MainWindow.ui.qml）

**功能**：左侧导航（6 个按钮：相机/光源/通信/异常检测/图像采集/设置），右侧 StackLayout 切换页面；窗口窄于 900px 时侧边栏折叠为纯图标。

**实现**：
```qml
Row {
    Rectangle { /* 侧边栏 */ 
        ColumnLayout {
            NavButton { id: btnCamera; text: qsTr("相机设置"); checked: true }
            NavButton { id: btnLight; ... }
            // ... 6 个按钮
            ButtonGroup { id: navGroup; buttons: [btnCamera, btnLight, ...] }
        }
    }
    Rectangle { /* 内容区 */
        StackLayout {
            currentIndex: navGroup.buttons.indexOf(navGroup.checkedButton)
            CameraPage {}   // 0
            LightPage {}    // 1
            // ... 顺序必须与按钮顺序一致！
        }
    }
}
```

**关键规则**：StackLayout 子项顺序必须与 `navGroup.buttons` 顺序一致（currentIndex 用 indexOf 计算）——加页面时必须两处同步。

**知识点**：
- **ButtonGroup**：让一组按钮"互斥选中"（单选）。
- **StackLayout**：一次只显示一个子项（其余隐藏但**仍实例化**）——所以非当前页的 QML 也在运行（Timer 会跑、信号会接）。
- **.ui.qml 文件**：仅供 Qt Design Studio 使用，**不要在里面加交互逻辑**（本项目逻辑都放页面文件里）。

## 六个页面

| 页面 | 功能 | 状态 |
|---|---|---|
| CameraPage | 搜索/连接/断开相机、参数读写 | ✅ 真实后端 |
| LightPage | 光源控制器（串口）连接 + 4 路亮度调节 | ✅ CH340 串口 + `$L{n}={value}#` 协议 |
| CommPage | MQTT 云服务器连接 + 用户名密码/TLS + 测试消息 | ✅ paho-mqtt 后台连接 |
| DetectPage | 实时采集 + 推理显示 + ROI 框选 + 阈值告警 | ✅ 真实相机 + ONNX 实时推理 |
| CollectPage | 数据采集（定时保存图片） | ✅ 真实相机 + 后台节流写盘 |
| SettingsPage | 主题/语言/配色 + 使用说明 + 关于 | ✅ 实现 |

## 页面通用模式（每个页面几乎一样的骨架）

```qml
Item {
    // ① 页面状态（property 声明）
    property bool _connected: false

    // ② 背景
    Rectangle { color: Colors.pageBg
        Flickable {                 // 内容可滚动
            ColumnLayout {          // 420px 居中栏
                width: 420
                x: Math.max(0, (parent.width - width) / 2)
                // 标题行
                Text { text: qsTr("页面名"); font.pixelSize: 16; font.bold: true }
                // 卡片（minipages/）...
            }
        }
    }
    // ③ 模拟/定时器（联调前用 Timer 伪造后端行为）
    Timer { interval: 1000; running: ...; onTriggered: ... }
}
```

DetectPage 例外：它是"图像页"，用**宽布局**（图像窗口占满剩余空间），控制操作收在右侧可展开的隐藏侧栏（侧栏展开时内容区 rightMargin 跟随避让）。

## 知识点

- **Flickable + ColumnLayout 居中**：`x: Math.max(0, (parent.width - width) / 2)` 让 420 栏在宽屏居中、窄屏贴左。
- **页面根不要写 `anchors.fill: parent`**：StackLayout 管理子项几何，写了会刷 QML 警告（已修复：6 个页面全部移除）。

## DetectPage 图像窗口内工具（ROI / 全屏）

- 原图标题栏与“原图”同一行：ROI 绘制按钮、全屏按钮。
- ROI：点击后显示绘制提示 + 红框；拖动实时显示像素范围；松开出现[确定]/[重绘]；
  确定后调用 CameraBridge.applyRoi，相机输出即 ROI 区域。
- 全屏：原图/异常热力图窗口均可点击 ⛶ 放大到整个 DetectPage，再点 ⛶ 恢复。

## ROI 恢复与比例说明

- 恢复按钮 `↺` 恢复到“首次框选 ROI 前”的相机设置分辨率，而不是永远最大分辨率。
- RoiOverlay 归一化坐标按实际图像内容区（剔除 letterbox 黑边）计算，
  避免框选画面与最终相机 ROI 之间出现比例/偏移误差。
