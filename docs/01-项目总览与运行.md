# 01 项目总览与运行

## 目录结构

```
DuAD_Software/
├── DuAD_SoftwareContent/          # 前端：入口 + 全部 QML
│   ├── main.py                    # 程序入口（Python 侧）
│   ├── App.qml                    # 根窗口（无边框 + 自定义标题栏 + 说明页）
│   ├── MainuiRoot.qml             # 窗口内容包装
│   ├── MainWindow.ui.qml          # 侧边栏 + 页面导航（Qt Design Studio 文件）
│   ├── DuAD_Software/             # QML 模块（Colors/Constants 单例）

├── backend/                       # 后端（复用老项目 pyqt5 代码改造）

├── tests/                         # 冒烟测试脚本
└── docs/                          # 本文档
```

## 启动流程（main.py 里发生了什么）

```
main.py 执行顺序：
1. 注入 LD_LIBRARY_PATH（backend/libs）→ 缺则自动重启进程
   —— glibc 的 dlopen 只认进程启动时的 ld 路径，运行时设置无效
2. 设置 QT_QUICK_CONTROLS_STYLE=Fusion
   —— KDE 桌面注入的 Breeze 样式与 Qt 6.11 QML 化控件不兼容（下拉框空白）
3. 创建 QGuiApplication（Qt 应用对象）
4. 注册全局字体（wqy-microhei.ttc）
5. 创建 QQmlApplicationEngine + 设置 QML 导入路径
6. 创建 AppBridge（语言/跨页状态）→ 注册为 QML 上下文属性
7. 创建 CameraBridge（相机桥）→ 注册为 QML 上下文属性
8. 加载 App.qml（QML 侧入口）
```

## 架构分层（MVC 思想）

```
┌─────────────────────────────────────────────────┐
│  QML 层（View + Controller）                     │
│  页面 / 组件 / 对话框 — 只管界面与交互            │
└──────────────┬──────────────────────────────────┘
               │ 通过 context property 调用（Slot/Property/Signal）
┌──────────────▼──────────────────────────────────┐
│  Python 桥层（Bridge）                           │
│  AppBridge（状态中枢）/ CameraBridge（相机）     │
│  把后端能力翻译成 QML 能调用的接口               │
└──────────────┬──────────────────────────────────┘
               │ 直接调用
┌──────────────▼──────────────────────────────────┐
│  后端层（backend/）                              │
│  相机驱动 / 采集管线 / ONNX 推理                 │
└─────────────────────────────────────────────────┘
```

**核心思想**：QML 不直接碰硬件/算法，一切通过 Python 桥中转。桥保持 Python 侧引用（防 GC），QML 里引用失败会"静默失效"（点了没反应），这是最容易踩的坑。

## 知识点

- **QGuiApplication vs QApplication**：QML 应用用 QGuiApplication（无 QWidget 能力），这是为何老项目的 QFileDialog 在新前端不可用、需要自绘目录选择器。
- **context property**：`engine.rootContext().setContextProperty("AppBridge", bridge)` 让 QML 里任何地方能直接访问 `AppBridge.xxx`。
- **Fusion 样式强制**：`os.environ.setdefault("QT_QUICK_CONTROLS_STYLE", "Fusion")` 必须在创建应用前设置（环境变量）。
