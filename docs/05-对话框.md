# 05 对话框

本项目有两个自绘对话框（`pages/components/`），都绕开了原生对话框——因为 **Qt 6.11 的原生对话框（FolderDialog 等）无法控制窗口尺寸**（是平台对话框包装，没有 width/height 属性）。

## HelpDialog — 使用说明页

**功能**：首次启动弹出（介绍每个页面的用途），设置页"使用说明"按钮可随时重开；显示过一次后不再自动弹（QSettings 记忆）。

**实现方式**：
```qml
Dialog {
    modal: true
    title: qsTr("使用说明")
    width: root.hostWindow ? root.hostWindow.width : 800   // 铺满主窗口
    height: root.hostWindow ? root.hostWindow.height : 600
    onOpened: AppBridge.markHelpShown()   // 打开即标记"已看过"

    contentItem: ColumnLayout {
        Flickable { /* 6 个说明条目，每项：图标 + 页面名 + 一句话说明 */ }
        Button { text: qsTr("开始使用"); onClicked: root.close() }
    }
}
```

- **声明位置**：必须在 **App.qml 窗口根**（场景坐标 = 窗口坐标，天然铺满）。嵌套在页面里会相对声明父偏移（见下面的目录选择器）。
- **显示时机**：App.qml 的 `Component.onCompleted` 里查 `AppBridge.shouldShowHelp()`，首次则延迟 400ms 弹出（等窗口就绪）。
- **再次打开**：AboutCard 按钮 → `AppBridge.helpRequested()`（Python 信号）→ App.qml 连接该信号打开对话框。

**知识点 — QML 调用 Python 信号**：直接函数调用（`AppBridge.helpRequested()`），**不能用 `.emit()`**（QML 里 emit 不存在，会报 TypeError）。

## DirectoryPickerDialog — 目录选择器

**功能**：自绘的目录浏览对话框（替代原生 FolderDialog），用于定时保存的"保存路径"选择。铺满主窗口、模态、可进入子目录/返回上级。

**实现方式**：
```qml
Dialog {
    property var hostWindow: null        // 主窗口引用（控制尺寸）
    property string startFolder: ""      // 初始目录
    property string currentFolder: ""    // 当前浏览目录
    signal folderSelected(string path)

    // 目录列表数据源：FolderListModel（Qt.labs.folderlistmodel）
    FolderListModel {
        id: dirModel
        folder: "file://" + root.currentFolder
        showFiles: false                 // 只显示目录
    }

    ListView {
        model: dirModel
        delegate: ItemDelegate {
            // 注意：用 model.filePath（fileURL role 在 Qt 6.11 是 undefined！）
            onClicked: root.currentFolder = model.filePath
        }
    }
    // "上级"按钮：dirModel.parentFolder
    // "选择此文件夹"按钮：emit folderSelected(currentFolder) + close
}
```

### 三个大坑（都是实际踩过的）

1. **Dialog 相对声明父定位**：Qt 6.11 的 Dialog 是 QML 实现，`open()` 时 placement 会覆盖 x/y 绑定，且**相对声明父**定位（不在窗口 Overlay 上）。修复：`onOpened` 里用 `mapToItem(null, ...)` 反向偏移对齐窗口原点：
   ```qml
   onOpened: {
       var host = root.mapToItem(null, 0, 0)   // 声明父的场景坐标
       picker.x = -host.x                       // 反向偏移 → 左上角对齐窗口
       picker.y = -host.y
   }
   ```
2. **`~` 不自动展开**：QUrl 不展开 `~`，且不存在的目录会静默 fallback 显示错乱。通过 `AppBridge.homeDir`（Python 返回 `Path.home()`）展开，`AppBridge.isDir(path)` 校验，无效则回退主目录。
3. **fileURL role 是 undefined**：FolderListModel 的 `fileURL` 在该版本取不到，用 `filePath`（本地路径字符串）。

### 知识点

- **FolderListModel**：Qt 提供的"列目录"模型（只显示目录用 `showFiles: false`）。`parentFolder` 属性可拿上级目录。
- **模态（modal）**：模态 Popup 打开时，窗口其他区域不可点击（有遮罩），这是"打开浏览后不会误点别处"的关键。
- **Popup 不在 Item 树里**：写测试时 `walk` 找不到它，要用 `findChildren(QObject)` 查找。

## 知识点总结

- 原生对话框（FileDialog/FolderDialog）是平台窗口，**不可控尺寸** → 本项目全部自绘。
- Dialog 的 contentItem 可以完全自定义（标题、内容、按钮自己排）。
- QML 的 `url.toString()` 返回 `file:///path` 形式，要转本地路径需 `decodeURIComponent(s.slice(7))`。
