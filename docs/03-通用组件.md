# 03 通用组件

`pages/components/` 下的组件是构建所有页面的"积木"。它们遵循统一的设计约定（label 列 72px、数值列 80px），让不同页面的控件视觉对齐。

## SliderRow — 滑块 + 数值

**功能**：拖动滑块调整数值，右侧数值可直接点击输入；支持鼠标滚轮细调与标准刻度吸附。

**实现要点**（`SliderRow.qml`）：
```qml
RowLayout {
    id: rowRoot
    signal released(real value)          // 松开滑块时发出
    property real sliderValue: 0         // 当前值（双向绑定用）
    property real from: 0                // 范围下限
    property real to: 100                // 范围上限
    property alias enabled: control.enabled
    property real resetValue: NaN        // 重置目标；NaN = 不显示重置按钮

    Text {                               // ① label 固定 72px（对齐约定）
        Layout.preferredWidth: 72
        elide: Text.ElideRight
    }

    Item {                               // ② 轨道区（fillWidth 吃掉剩余空间）
        id: control
        readonly property real ratio: (to > from)
            ? (sliderValue - from) / (to - from) : 0
        Rectangle { /* 轨道 */ }
        Rectangle { /* 已填充轨道 */ }
        Rectangle { /* 手柄：x = ratio * (track.width - width) */ }
        MouseArea {
            onPressed: setValue(mouseX)                       // 按下定位
            onPositionChanged: if (_pressed) setValue(mouseX) // 拖动跟手
            onReleased: { _pressed = false; rowRoot.released(sliderValue) }  // 松开才提交
        }
    }

    Text {                               // ③ 数值列固定 80px
        text: sliderValue.toFixed(decimals) + suffix
    }

    Button {                             // ④ 重置按钮（resetValue 非 NaN 才显示）
        visible: !isNaN(resetValue)
        onClicked: {
            sliderValue = resetValue
            rowRoot.released(resetValue) // 触发提交（与拖动松开语义一致）
        }
    }
}
```

**设计决策**：
- **松开才提交**：写相机等重量级操作挂 `onReleased`（拖动过程实时预览数值、不写相机），避免拖动时频繁 IO。
- **重置按钮**：`resetValue` 默认 NaN（不显示），调用方传入目标值即启用——向后兼容所有旧用法。
- **没有用 QML 原生 Slider**：为了自定义外观（细轨道、圆形手柄、label/数值对齐），自己用 MouseArea 实现了交互。

**知识点 — alias 的坑**：`property alias enabled: control.enabled` 是"属性别名"（转发到 control 的 enabled）。注意不要在 `control` 内部再声明 `property bool enabled: true`——那会遮蔽 QML 原生 enabled 导致**级联禁用失效**（父级 disabled 传不进来）。本项目踩过此坑（SaveSettingsPanel 参数锁定一度失效）。

## InputRow — 文本输入行

**功能**：label + 输入框（支持密码模式、占位符）。

```qml
RowLayout {
    property alias text: field.text            // 把内部 TextField.text 暴露出去
    property alias placeholderText: field.placeholderText
    property bool password: false
    signal textEdited(string newText)          // 自定义信号：携带新文本

    Text { /* label 固定 72px */ }
    TextField {
        id: field
        echoMode: password ? TextField.Password : TextField.Normal
        onTextEdited: parent.textEdited(text)  // 转发给父组件信号
    }
}
```

**知识点**：
- `property alias` 让外部可以直接 `text: "hello"` 读写输入框内容。
- 信号转发模式：子控件信号 → 父组件自定义信号 → 页面处理（解耦层级）。

## ComboRow — 下拉选择行

**功能**：label + ComboBox 下拉框（支持"稳定 key + 显示函数"模式）。

**关键约定**：**model 用稳定 key（不翻译），显示文本走 displayFunc**——
```qml
ComboRow {
    model: ["light", "dark", "system"]      // 稳定 key，不随语言变化
    displayFunc: function(key) {            // 显示文本实时求值（可翻译）
        if (key === "light") return qsTr("亮色")
        ...
    }
}
```
**为什么**：语言切换时若 model 是翻译后的文本，ComboBox 会重建模型 → currentIndex 被重置。用稳定 key + displayFunc 则模型不变、只改显示。

**下拉框的坑**（已踩）：
- Qt 6.11 的 ComboBox 是 QML 实现，popup 高度依赖 delegate 异步布局 → KWin 下形成"0 高→无 delegate→仍 0 高"死循环（下拉空白）。修复：**高度用 `combo.count * 32 + 4` 同步计算** + `popupType: Popup.Item`（窗口内渲染）。
- KDE 的 Breeze 样式与 Qt 6.11 QML 化控件不兼容（下拉空白）→ main.py 强制 Fusion。

## SwitchRow — 开关行

**功能**：label + pill 风格开关。

```qml
RowLayout {
    property alias on: toggleBtn.on          // 开关状态
    signal toggled()                         // 切换信号

    Button {
        id: toggleBtn
        checkable: true
        onClicked: { on = !on; parent.toggled() }   // 自翻转 + 通知
        background: Rectangle { /* pill 样式：on 用主题色，圆形滑块 x 动画 */ }
    }
}
```

**用法模式**（页面里必须回写状态）：
```qml
SwitchRow {
    on: AppBridge.algorithmEnabled           // 显示后端状态
    onToggled: AppBridge.algorithmEnabled = on   // 用户切换 → 写回后端
}
```
**坑**：SwitchRow 内部点击会破坏 `on:` 的外部绑定，所以**调用方必须在 onToggled 里回写**状态（否则开关只动一下、状态不同步）。
