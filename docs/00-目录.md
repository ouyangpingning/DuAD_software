## 快速上手

```bash
# 运行软件
source DuAD_SoftwareContent/pyqml/bin/activate
python DuAD_SoftwareContent/main.py
```

技术栈：**PySide6 (Qt 6.11) + QML（前端）**，**Python（后端：大恒相机 SDK + ONNX 推理）**。
